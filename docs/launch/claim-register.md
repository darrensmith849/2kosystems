# 2KO public claim register

Public proof is valuable only when 2KO can reproduce the source behind it. This register is the release control for factual, numerical and client-association claims.

Status meanings:

- **Approved** — a named owner has checked the source and authorised the exact wording.
- **Needs evidence** — the claim may be true, but the launch folder does not yet contain a sufficient source.
- **Restricted wording** — evidence supports a narrower statement than the strongest possible interpretation.
- **Illustrative only** — the material demonstrates a concept and must not be presented as a client outcome.

## Evidence file requirements

For each approved claim, store:

1. the exact approved wording;
2. the source file, link or system report;
3. the measurement definition and cutoff date;
4. the approving person and approval date;
5. any expiry or review date; and
6. any limitation that must accompany the claim.

Review this register quarterly and whenever pricing, product availability, client logos or training programmes change.
