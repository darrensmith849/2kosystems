# Client logo evidence

This register records the evidence used for the September 2026 client-strip
expansion. It deliberately contains aggregate domain counts only. Individual
delegate names and email addresses remain in the source workbook and are not
copied into the website repository.

Source: `White  Yellow Belt Online Delegates (Latest)(AutoRecovered).xlsx`

Method:

1. inspect the White Belt and Yellow Belt records;
2. normalise the email domain and exclude personal email providers;
3. count corporate-domain records without retaining individual addresses;
4. select recognisable organisations with repeated records and a clear domain;
5. use the restrained public wording “Organisations served across the 2KO Group.”

The workbook contains 2,350 valid email addresses. Of these, 673 use 233
distinct non-personal domains. A domain count confirms that people using the
organisation’s domain appear in the training record. It does not establish the
scope, buyer, contract value or permission to describe a detailed engagement.
